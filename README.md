# Backend Job Prep

Spring Boot로 회원·게시글 API를 구현하며 Java, JPA, 테스트, Docker를 학습하는 프로젝트입니다.

## 주요 기능

- Health API
- 회원 등록·조회
- 게시글 등록·조회
- 회원과 게시글의 JPA 연관관계
- 지연 로딩과 fetch join 비교

## 개발환경

- GitHub Codespaces
- VS Code
- Spring Boot Extension Pack
- Java 21
- Maven Wrapper
- Docker 선택 사용
