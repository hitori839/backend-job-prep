## 오늘 배운 것

- Map은 회원 ID로 객체를 저장하고 찾을 때 사용할 수 있다.
- Optional은 찾는 객체가 없을 수도 있을 경우에 사용할 수 있다.
- In-Memory Repository로 DB를 임시 대체 할 수 있지만, 계속 내용이 저장되지 않고 종료되면 그 즉시 삭제된다.
- @Repository는 DB 연동을 담당하는 클래스에 붙이는 스프링 어노테이션이다.
-> 클래스를 스프링 빈으로 자동 등록하고, DB 전용 예외를 일관된 스프링 예외(DataAccessException)로 일괄 전환해준다.
- java.util.concurrent.atomic.AtomicLong은 멀티스레드 환경에서 공유하는 Long 값을 읽어야 할 때 사용한다. (동시 수정 방지를 위해)
- Bean은 스프링이 생성하고 관리하는 자바 객체이다.
