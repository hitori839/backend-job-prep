# 2026-09-01 학습 기록

## 오늘의 목표

GitHub Codespaces에서 Spring Boot를 실행하고 GET /health API를 만든다.

## 새로 배운 개념

- GitHub 저장소와 Codespaces의 차이
- 서버와 API의 의미
- GET 요청과 JSON 응답
- @RestController와 @GetMapping
- HTTP 200, 404, 500 상태 코드

## 구현한 기능

- HealthController
- GET /health
- HealthControllerTest

## 테스트 결과

- ./mvnw test 성공
- GET /health 응답 확인

## 오늘 발생한 오류

1. 4.5 부분에서 Whitelabel Error Page에러가 뜨길래 헷갈렸었다.
- 원인은 서버는 켜졌지만 보여줄 화면이 없었던 것이 었다. 따라서 TestController 클래스 생성하여 문구를 보여주게 하였다.

2. pom.xml 에러 
- 잘못된 부분
-- spring-boot-starter-webmvc 및 spring-boot-starter-webmvc-test
-- <parent> 태그 누락
-- <build> 영역 누락

- 수정
-- spring-boot-starter-web 및 spring-boot-starter-test
-- 나머지는 추가

## 아직 헷갈리는 부분

- 잘못된 부분에서 왜 잘못되었는지 더 이해가 필요하다.
